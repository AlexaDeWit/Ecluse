Écluse

Most damage from a malicious package publish happens in the first days, before the ecosystem notices and pulls the version. Écluse makes a build late instead of trying to detect malice. Every new version waits in a quarantine, seven days by default, before a build can install it. A version that an advisory names as the fix for a vulnerability skips the queue, so the quarantine never delays a security patch. Écluse runs in front of the registry you already have, AWS CodeArtifact today. It reads your private registry first, gates the public one, and mirrors approved versions into yours with the cloud's own identity. It hosts nothing.
